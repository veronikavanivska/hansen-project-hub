# Hansen Project Hub - demo PL/EN

Branding aligned to Hansen Polska using the supplied logo and the monochrome visual direction of hansenpolska.eu.

## Run
```bash
npm install
npm run dev
```

Language switch: PL / EN. The selected language is stored in localStorage.

All project values and generated documents in this demo are illustrative. Public project names are used only as presentation references.
